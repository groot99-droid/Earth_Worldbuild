## Tool reference (`_RAG/tools/`, documented in `_RAG/README.md`)
- `fetch_source.py`: `fetch "<title>" [--force]` or `fetch --url URL --slug NAME` (use `slugify(title)` as the slug for a new source so `pick_slug` finds it); `claims`, `grep`, `batch --tier N -n K`, `checks --tier N | --source "<title>" [--missing-only] [--complete-only] [--top] [--width]`, `relevel`, `biblio`, `queue build|status|next|mark`.
- Routes: papers (Europe PMC full text, OpenAlex OA PDF, publisher page, PubMed abstract, OpenAlex, Crossref, Wayback), Wikipedia (API), Britannica and other blockers (Wayback `web/2id_/`, CDX fallback), everything else (direct then Wayback). Levels: `full-text`, `archived-copy`, `reference-text`, `abstract`, `metadata`, internal `supplement`.
- `apply_patch.py spec.json [--dry]` keys: `date`; `sources_new` (title, citation, url, kind, reliability, access, access_route, read_on, used, caveats); `source_updates` (title, `set`, citation, used, caveats, replace, mark); `notes` (note, `replace` [[old,new]] exact-once, `checks`, `replace_checks` [[substring of one existing check, FULL new claim ending in [Source]]], `drop_checks`, `sources`); `discrepancies`. A check must end with **exactly one** trailing `[Source A; Source B]` bracket listing every source for that whole claim, contain no double quotes, and cite existing or new source titles: `checks --source` finds a check only by its trailing bracket, so a claim needing two different sources for two different clauses needs two separate `checks` entries, never one entry with two embedded brackets (a real Tier 4 bug: see discrepancies.md 2026-09-27). Backups go to `_RAG/source_cache/patch_backups/<run>/`.
- `t2_build.py` (the Caveats/access builder) branches on the fetch route: `wikipedia-api` gives "MediaWiki API raw wikitext, revision `<id>`"; add a branch there for any new route the fetcher grows.
- `audit_claims.py [--root DIR] [--out f.json]`: a bullet counts as covered only when every 3+-digit number and half its capitalised names appear in the note's `fact_checks` line, so write "about 1410 to 1415", not "1410-15". The JSON is a list of `{name, bullets, covered, qualitative, uncovered:[...]}`.

## Rules and gotchas that cost time
- When a source's cached text contradicts a check, also re-read that source note's own `## What It Is Used For` text: it can independently repeat the same wrong or unconfirmed detail (found in Tier 4 for 6 of 8 corrected sources). Fixing only the citing note's check is not enough.
- No CAPTCHA, cookie-wall, login-wall or paywall circumvention (Science's free-access copy needs an account: not done). 403 is logged once, never retried; 429 backs off up to twice.
- The contact email sits only in `_RAG/fetch_config.local.json` (git-ignored) or env `EARTH_FETCH_EMAIL`; it goes only to Crossref, OpenAlex, NCBI and Wikimedia; never write it into a note, log or reply. Do not use the user's Anthropic-account email.
- Do not patch code with Python-in-heredoc when strings contain `\n` or backslashes: use the Edit or Write tool. Foreground `sleep` is blocked: use `run_in_background`. Set `PYTHONIOENCODING=utf-8`. Titles piped through Python output may carry `\r`.
- Britannica archived pages are complete short articles; missing details are usually really absent (but check for stubs: the Sugar Revolution page is a search-excerpt stub, the Napoleonic Wars source used to point at the Austerlitz page). Wayback captures of science.org, pnas.org and sciencedirect often 403 or loop (`TooManyRedirects`); the CDX fallback handles some. `britannica.com/event/...` and `/topic/...` URLs are not interchangeable: try both if one has no snapshot (Scramble for Africa is under `/event/`).
- Never soften a hedge ("debated") away; only delete or replace specific figures, and log removed text in `discrepancies`. Abstract-only reads confirm only what the abstract states.
- Titles must stay unique vault-wide; do not rename source notes (links are by title); fix URLs and citations instead. A citation that bundles pages that were not read is cut back to the page read, with the cut recorded in Caveats (`t2_build.py` does this for " Also ...").
- The `Encyclopaedia Britannica` and `English Wikipedia` notes are homepages: `access: not-consulted`, `verified: false`.
